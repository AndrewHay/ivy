# Parthenocissus tricuspidata — Boston ivy candidates (`ivy-mx5.7`)

*Parthenocissus tricuspidata* (Boston / Japanese creeper). Ivy-like wall coverage; lobed leaves turn red in autumn. Different genus from *Hedera*.
