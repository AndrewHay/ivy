# M2 acceptance gate measurement.
#
# Grows the plant to game-days 30, 60 and 150 and emits DUMP_METRICS at each
# checkpoint.  Seed is at south (azimuth 180°, the M1 default) so the sun-
# facing half is the south half and shade is north.
#
# DUMP_METRICS 180 = seed_azimuth_deg=180 (south seed).
#
# AS-1 targets (ratified DESIGN.md 2026-08-09):
#   ≥70% overall / ≥90% sun-facing / ≥50% shaded  (at day 150)
# AS-2 targets:
#   ≥20% stem asymmetry at day 30 / ≥40% at day 60 / ≥30% at day 150
# AS-3(a): midnight gate ≤15% daily mean, ≤10% noon rate  (any day)

# Screenshots are taken six game-hours past each checkpoint, at local noon.
# `start_hour` is 6.0 and `day_of_year` is fixed at 105, so a whole number of
# days always lands at 06:00 with the sun a few degrees above the horizon —
# useless for judging leaf legibility, sun/shade asymmetry or exposed wall. The
# metric dumps stay on exact whole-day tick counts, and each +0.25 is paired
# with a +0.75 so every checkpoint lands on the same tick as before: 720, 1440,
# 3600. Metrics are unaffected by the offset regardless; they read the plant and
# the field, not pixels.
