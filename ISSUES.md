# Issues

Track gameplay bugs in the GitHub issue tracker for this repository once it exists.

Until then, use this file for local triage notes or link issues from `AndrewHay/ivy` when the remote is created.

## Bug report template

- Context and affected build/branch
- Reproduction steps
- Expected behavior
- Actual behavior
- Severity (blocker/high/medium/low)
- Affected systems/files (if known)
