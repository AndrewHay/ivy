# Game Design Philosophy

The goal of this project is to build interesting gameplay systems with clear player feedback.

Priorities:
1. Strong gameplay loops
2. Clear player agency
3. Simple rules with emergent behavior
4. Systems that interact with each other

Avoid:
- unnecessary complexity
- mechanics that do not serve the core gameplay loop
- features that expand scope without improving player experience

When designing or implementing systems:
- always consider how the player understands the mechanic
- prioritize clarity and feedback
